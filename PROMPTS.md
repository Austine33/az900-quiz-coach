# Prompts I used

## 1. Writing the questions (Claude)
Write 5 easy multiple-choice questions about [topic] for AZ-900 beginners. For each question give: the question, 4 options A to D, the correct answer, and a simple explanation of why it is correct. Make them original, not copied from the real exam.

I used this for 3 topics: cloud computing, Azure architecture and services, and Azure management and governance. I then checked every answer on Microsoft Learn.

## 2. Building the website (Bolt)
Build a simple quiz website called AZ-900 Quiz Coach (Unofficial). It shows one question at a time with 4 answer buttons. After I pick an answer, it tells me if I was right or wrong, and shows the correct answer and the explanation. At the end it shows my score. Make it colourful and easy to use on a phone. Use ONLY the questions I provide, exactly as written.
