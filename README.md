# AZ-900 Quiz Coach (Unofficial)

An unofficial study tool for Microsoft Azure Fundamentals (AZ-900) learners. It is not affiliated with or endorsed by Microsoft.

## The problem
While preparing for AZ-900, I studied from Power Learn Project (PLP) learning materials, PLP virtual recap sessions and YouTube videos. Practising questions was not enough, because I often did not understand WHY an answer was right or wrong.

## The solution
AZ-900 Quiz Coach gives instant feedback and a simple explanation for every answer, so learners understand each concept instead of memorising it.

## Features
- 15 original questions (not copied from the real exam)
- Questions grouped by the 3 AZ-900 skill areas: Cloud Concepts, Azure Architecture and Services, Management and Governance
- Instant right or wrong feedback
- A clear explanation after every answer
- A final score
- Works on phones and computers
